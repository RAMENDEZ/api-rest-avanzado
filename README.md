# API REST de Gestión Escolar - Backend Avanzado

API REST profesional para la administración de estudiantes y materias construida con Node.js, Express, Prisma ORM y PostgreSQL. Cuenta con validaciones avanzadas mediante Zod, encriptación con bcryptjs, y protección de accesos a través de API Key y Tokens JWT.

## 🚀 Tecnologías Utilizadas

*   **Entorno de ejecución:** Node.js (v24.14.1)
*   **Framework Web:** Express.js (v5.2.1)
*   **ORM:** Prisma ORM (v7.8.0) con adaptador para PostgreSQL (`pg`)
*   **Validación de Datos:** Zod (v3.23.3)
*   **Seguridad y Autenticación:** 
    *   jsonwebtoken (v9.0.2)
    *   bcryptjs (v2.4.3)
*   **Herramientas de Desarrollo:** nodemon (v3.1.14) y pnpm como gestor de paquetes.
